WasteWise Management 

## Project Description

WasteWise is an AI-enabled waste management platform that promotes proper waste segregation, recycling, and sustainable disposal for a cleaner environment. It provides users with waste management guidance, an interactive dashboard, and analytical insights to support responsible waste management.

## Problem Statement

Improper waste segregation and disposal can lead to environmental pollution and unhealthy communities. WasteWise aims to encourage people to manage waste responsibly through technology-driven solutions.

## Features

* Waste segregation guidance
* Interactive waste management dashboard
* Waste analytics and data visualization
* Sustainable waste disposal awareness
* AI-enabled waste management support

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
* Data Visualization

## How to Run the Project

1. Clone the repository:

   ```bash
   https://github.com/suhanivgani-eng/Wastewise-Management-project
   ```

2. Open the project folder:

   ```bash
   cd WasteWise
   ```

3. Install Flask:

   ```bash
   pip install flask
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open the local URL in your browser:

   ```text
   http://127.0.0.1:5000
   ```
